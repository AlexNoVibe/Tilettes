Windows 用の高速起動パネル：ショートカット・フォルダー・タブをまとめたタイルグリッド、あいまい検索、コンソール内蔵のミニエクスプローラーを搭載。単一のポータブル EXE、インストール不要、.NET Framework 4.8 (WinForms)。

![Tilettes — メインウィンドウ](screenshot_main.png)

現在のバージョン：**v1.1.0** — ダウンロード：[Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest) · [更新履歴](#changelog)。ステータス：**beta**。

## ハイライト

**タイルとタブ** — 1×1…6×6 のタイル。スキン（Mint、Night、Android）とライト/ダークのテーマ。カスタムのフォントと色。無制限のドラッグ可能な複数行タブ、フリー/グリッドレイアウト。タブ内またはポップアップで開くフォルダー。グリッドの下にはスクロールできる追加の行。複数選択編集モードとドラッグ＆ドロップ。タイルごとにカスタムの名前、説明（検索対象）、アイコンを設定でき、タイル上には写真/動画のプレビューも表示されます。

**検索** — 名前、プログラムのメタデータ（説明 / 製品 / 会社名）、フルパス、ユーザー説明を対象にした即時のあいまい検索。キャッシュ済みのメタデータに対して動作します（ディスクスキャンなし）。誤ったキーボードレイアウトも修正されます（`знерщи` → `python`）。結果は 2 つのブロックに分かれます — 上に過去のクエリ（実際のアイコン付き。セッションをまたいで記憶され、上位に押し上げられます）、下に通常の結果。検索対象はそれぞれオン/オフを切り替えられます。

**軽量** — ~0.5 MB (517 KB) のポータブル exe 1 つだけ。データはすべてその隣に。依存先は Windows に組み込まれた .NET Framework のみ。RAM は ~30 MB。アイコンはタイルの生存期間中に 1 回だけシェルから抽出され、自動でクリーンアップされる `iconcache\` に保存されます。アプリの起動がパネルをブロックすることはありません（プロセスは分離、ネットワークパスはバックグラウンドで処理）。起動時に描画されるのはアクティブなタブだけです。

**ミニエクスプローラー** — パンくずナビゲーション、フォルダー/コマンド/グループのブックマーク、内蔵 `cmd.exe` コンソール（履歴、Ctrl+ホイールでのフォント拡大）。お気に入りのコマンドはクリック 1 つで実行でき、`%1` は閲覧中のフォルダーに展開されます（`wt -d "%1"`）。拡張子/マスクごとの「アプリで開く」ルール（インポート/エクスポート対応）。

**システム** — スケジュールに従って同期されるミラーされたスタートメニュータブ（UWP/Store アプリを含む）。グローバルホットキー、オプションの Win キーの捕捉、タスクトレイ、自動起動。エクスプローラー純正のコンテキストメニュー。スケジュールおよび手動のバックアップと、ワンクリックでの復元。UI は 10 言語。

**オープンソース** — 完全なオープンソース。リリースはタグをもとに GitHub Actions がビルドし、`SHA256SUMS.txt` を添付。アプリ全体で発生するネットワーク通信は更新確認（オプトイン）のただ 1 回のみ。テレメトリーは一切ありません。

## 特徴

- **パネル** — 1×1…6×6 のサイズのタイル、無制限のタブ（ドラッグ可能、複数行）、タブ内またはポップアップで開くフォルダー、エクスプローラーからのドラッグ＆ドロップ、カスタムグリッド（列数/行数/透明度）、アイコン倍率。
- **検索** — 名前、ファイル名、プログラムのメタデータ（FileDescription / ProductName / CompanyName）、フルパス、ユーザー説明を対象に検索。設定によりミラーされたスタートメニュータブも対象に含めます。精度を調整できるあいまいマッチングと、誤ったキーボードレイアウトの修正（`руддщ` → `hello`）に対応。結果はマッチの品質でランク付けされ、一致した文字はハイライト表示されます。同じクエリを繰り返すと履歴によって上位に押し上げられます。入力中のクエリがある場合、結果は 2 つのブロックに分かれます — 上に記憶された過去の同じクエリ、下に通常の結果（完全な重複は 1 つにまとめられます）。過去検索の行には、記憶されたアイテムの実際のアイコンが表示されます。
- **ミニエクスプローラー** — パンくずナビゲーション、フォルダー/コマンド/グループのブックマーク（コマンドには `%1` を含められます。これは閲覧中のフォルダーに展開されます — 例：`wt -d "%1"` でその場で Windows Terminal を開く）、コマンド履歴・保存されたコマンド・Ctrl+ホイールでのフォント拡大に対応した内蔵 `cmd.exe` コンソール。（ファイル検索モジュールは v0.6.0-beta から無効化されています — 将来の再有効化に備えてスタブが残されています。）
- **ファイルタイプルール** — 拡張子/マスクごとのアイコンと「アプリで開く」関連付け、インポート/エクスポート。
- **デスクトップ統合** — タスクトレイアイコン、Windows と共に自動起動、グローバルホットキー、オプションの Win キーの捕捉、エクスプローラー純正のコンテキストメニュー、縁のドラッグでリサイズできるボーダーレスウィンドウ。
- **スキンとその他の機能** — 装飾スキン（独自の配色 + 角丸のウィンドウ枠）、スケジュールに従って再構築されるミラーされたスタートメニュータブ、`autoBackup\` への完全バックアップ、パネル検索の履歴。
- **初回起動と更新** — 一度だけ表示されるウェルカムウィンドウ（「3 つのソース → タイルグリッド」の描画付き図解、言語選択、更新確認の許可、サポートへのリンク、サンプルタイル）と、GitHub Releases に対する更新確認。新しいバージョンがあるときは隅にプレートが表示されます。

## 初回起動と更新

- **ウェルカムウィンドウ**（初回起動時のみ）：感謝のメッセージ、バグや未完成の部分がある可能性についての注意書き（[Issues](https://github.com/AlexNoVibe/Tilettes/issues) へのリンク付き）、描画付きのミニ図解（フォルダー・.exe・.lnk のカード → 矢印 → 「+」のゴーストセルが置かれたタイルグリッド）、言語選択（10 個の旗ボタン）、更新確認の許可、[寄付セクション](https://github.com/AlexNoVibe/Tilettes#donate)への **作者を支援** リンク — そして 2 つの終了ボタン：普通に**閉じる**、または**閉じてサンプルタイルを作成**（メモ帳・電卓・エクスプローラー・ペイントがすぐ使えるタイルとして登録されます）。設定の「ウェルカムウィンドウをもう一度表示」から、いつでも再表示できます。
- **更新確認** — アプリは公開の GitHub Releases API に N 日ごと（既定 3 日）問い合わせます（初回の確認も、最初の起動直後ではなく N 日後に行われます）。データは一切送信されず、設定で更新確認をオフにすればネットワークリクエストは一切発生しません。新しいタグが存在する場合、設定ボタンの横に緑色の **⟳ 更新** プレートが表示され、クリックすると [Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest) ページが開きます。設定の「今すぐ確認」は間隔に関係なく手動で確認を実行します（結果はメッセージボックスで通知されます）。自動インストールは現時点ではスタブ (TODO) です。
- **テスト用フック** — `WINPANEL_MOCK_UPDATE=0.6` を付けてアプリを起動すると、新しいリリースが存在する場合と同じように更新プレートが描画されます（ネットワーク通信なし）。

## 設定リファレンス

すべての設定は 1 つのダイアログ（⚙ ボタン / タスクトレイメニュー）にまとめられており、`settings.ini` に保存されます。

### 起動とウィンドウ

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| 起動時サイズ (W × H) | 200–4000 | 900 × 800 | 起動するたびのパネルサイズ。セッション中のリサイズは保存されません — 保存されるのは位置だけです。 |
| ウィンドウ位置 (X, Y) | −4000…4000 | 100, 100 | 起動時の画面上の位置。ウィンドウを移動すると自動的に更新されます。 |
| ウィンドウ表示ホットキー | プリセット + カスタム | Ctrl+Q | パネルの表示/アクティブ化を行うグローバルホットキー。プリセット（None、Ctrl+Q、Ctrl+Shift+Q、Alt+Q、Ctrl+J など）を選ぶか、編集可能なフィールドに任意の `Mod+Key` の組み合わせ（Ctrl/Alt/Shift/Win + 英字または数字）を直接入力できます。解釈できない入力は説明付きで拒否されます。 |
| 言語 | en, ru, es, pt, de, fr, it, pl, zh, ja | ru | UI の言語（10 言語）。すぐに適用されます。 |

### グリッドとタイル

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| グリッドの透明度 | 0–255 | 50 | グリッド線のアルファ値。0 = 非表示。グリッド表示のトグル（▦）がオンのときのみ描画されます。 |
| グリッドの列数 | 1–100 | 16 | 水平方向のセル数。タイルの位置はこのグリッドにスナップします。 |
| グリッドの行数 | 1–100 | 16 | 垂直方向のセル数。 |
| 既定のアイテムサイズ | 1–6 | 2 | 新しく追加されるタイルのサイズ（1×1 … 6×6 セル）。 |
| アイコン倍率 (%) | 25–400 | 100 | タイル内のアイコンサイズ（既定値に対する割合 %）。 |
| アイコンの追加を許可 | オン/オフ | オン | 編集モード：タイルのドラッグ、フォルダーの作成、ファイルのドロップ。オフの間はタイルがクリックで起動するだけになります。 |
| タイルラベル：2 行 | オン/オフ | オン | 縦長のタイルではラベルが 2 行に折り返されます（2 行の配置 — 左/中央/右 — はその隣で設定します）。 |
| ショートカット接尾辞を隠す | オン/オフ | オン | 表示のみ：「 - Shortcut」/「 — ярлык」（ダッシュの異形、複数言語）がラベル上で隠されます。保存されている名前と検索には影響しません — 元に戻すにはチェックを外します。 |
| 拡張子を隠す | オン/オフ | オン | 表示のみ：アイテムのパスの実際の拡張子（.mp4 …）がラベル上で隠されます。元に戻すにはチェックを外します。 |
| スキンとテーマ | なし (ダーク) / ライト / スキン | Mint | 定番のダークまたはライトのテーマ、あるいは独自の配色とウィンドウ枠を持つ装飾スキン：Android、Night、Mint（出荷時の既定）。 |

### フォルダー

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| フォルダーの開き方 | 同じウィンドウ / ポップアップウィンドウ | 同じウィンドウ | フォルダーをクリックするとタブ内で開くか、すべての上に重なるポップアップで開きます。 |
| アイドル秒数 | 0–600 | 15 | 「同じウィンドウ」モード限定：マウス/キーボードの操作が N 秒間ないと自動的に上の階層へ戻ります。0 = オフ。 |

### フォント

**タイル**、**タブ**、**UI** の 3 つのグループにそれぞれ 1 行ずつ：

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| サイズ | 6–24 | 14 | そのグループのフォントサイズ。 |
| 色 | 任意の色 | 空 | カスタムの文字色。空 = テーマの既定色。タイルのラベル、タブのキャプション、またはすべての UI テキストに適用されます。 |
| 書体 | インストール済みの任意のフォント | Segoe UI | そのグループのフォントファミリー。 |

### 検索

| 設定 | 範囲 | 既定 | 説明 |

| メタデータを検索 | オン/オフ | オン | ファイル名、ショートカットのリンク先、バージョン情報（説明、製品、会社名）。 |

### 自動起動とタスクトレイ

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| Windows と共に自動起動 | オン/オフ | オフ | `HKCU\...\Run` に書き込みます（「Tilettes」）。 |
| 自動起動後はタスクトレイへ | オン/オフ | オフ | `--minimized` を付与：パネルはタスクトレイに隠れた状態で起動します。 |
| 閉じる代わりに最小化 | オン/オフ | オン | ✕ / Alt+F4 で終了せずにタスクトレイへ隠します（または最小化します）。終了はタスクトレイメニューから。 |
| タスクトレイアイコンを常に表示 | オン/オフ | オン | タスクトレイのアイコンが常に表示されます。 |
| アクティブなタブを記憶 | オン/オフ | オン | 起動時に最後にアクティブだったタブを復元します。 |
| スタートボタン (Win) の捕捉 | オン/オフ | オフ | Win キーの単独押下でスタートメニューの代わりにパネルを表示します（低レベルのキーボードフック）。Win+キーの組み合わせはそのまま通ります。オプトイン — 既定はオフです。 |

### バックアップとスタートメニュー同期

- **今すぐバックアップ** — `autoBackup\` への完全なバックアップ zip（設定、タイル、アイコン、ブックマーク、検索履歴、exe）。「N 日ごとにバックアップ」（既定 7 日、0 = オフ）でスケジュールされ、期限が来ていれば起動の約 3 分後に作成されます。
- **バックアップを保存 (zip)** — 同じアーカイブをユーザーが選んだファイルに保存します。
- **アーカイブを復元…** — Tilettes 自身が作成した zip のみを受け付けます。ファイルは作業フォルダーに展開され、`Tilettes.exe` が置き換えられることはありません。
- **スタートメニューを今すぐ同期** / N 時間ごと (既定 24、0 = オフ) — ミラーされたスタートメニュータブを再構築します。

## ホットキーとコマンド

### メインパネル

| キー / 操作 | 動作 |
|---|---|
| ホットキー（既定は Ctrl+Q） | パネルを表示 / アクティブ化します。 |
| Win キーの単独押下（オプトイン） | スタートメニューの代わりにパネルを表示 / 非表示にします — 設定で「スタートボタン (Win) の捕捉」を有効にしてください。 |
| テキストをただ入力する、または Ctrl+F | パネル検索を開きます。 |
| ↓ | 結果リストへ移動します。 |
| Enter | 選択した結果を開きます（フォルダー → 移動、ファイル → 起動）。 |
| Esc | 検索を閉じます。 |
| タイルをクリック | アイテムを起動します。フォルダーは移動します（設定によりポップアップ）。 |
| フォルダータイルを Ctrl+クリック | ミニエクスプローラーを開きます（有効な場合）。 |
| タイルをドラッグ（編集モード） | 移動します。フォルダーの上にドロップするとその中へ移動します。 |
| パネルへファイルをドロップ（編集モード） | タイルとして追加します（フォルダーの上にドロップするとその中へ追加）。 |
| タイルを右クリック | エクスプローラー純正メニューに加えて：説明…、サイズ 1×1–6×6、名前の変更、アイコンの変更、削除、フォルダーから取り出す、タブへ移動 ▸、ミニエクスプローラーで開く（フォルダーのみ）。 |
| タブを右クリック | 削除（最後のタブは保護対象）、名前の変更、フリー/グリッドレイアウトの切り替え。 |

### コンソール

1 行の `cmd.exe` コマンドなら何でも入力して実行できます（Enter または**実行**ボタン）。作業ディレクトリはコマンドごとに現在のフォルダーへ再同期されます。**+ 保存**は入力したコマンドをブックマークとして保存し（グループ内にも保存可能）、保存されたコマンドはクリックで実行できます。コマンドには `%1` を含められます — 閲覧中のフォルダーに展開されます（初期状態で同梱されている「CMD グループ」には、その場で Windows Terminal を開く `wt -d "%1"` ブックマークが入っています）。ボタン：**クリア**（出力の消去）、**再起動**（新しい cmd.exe）、**新しいウィンドウ**（現在のフォルダーで本物のコンソールウィンドウを開く）。コマンド履歴はセッション中であれば ↑ / ↓ でたどれます。

## 制限事項

- **Windows + .NET Framework 4.8 専用**（GDI/WinForms）。モニターごとの DPI 認識には対応していません — 高倍率のスケーリングが設定されたディスプレイでは UI がにじむことがあります。
- **ミニエクスプローラーのファイル検索は無効**です（v0.6.0-beta 以降）：ディスクインデックス化モジュール（ローカルの固定ドライブのみ、ドライブあたり 200 000 件まで）は、将来の再有効化に備えてスタブとして残されています。パネル検索は保存済みアイテムのキャッシュ済みメタデータのみを対象に動作します — ディスクインデックス化は行いません。
- **パネル検索**は上位 **200** 件を表示します。ファイルリストは 1 ディレクトリあたり最大 **800** 件です。
- **コンソールは `cmd.exe` のみ**：コマンドは 1 行のみ。対話型/TUI プログラム（エディターやキー入力を受け付けるページャーなど）は正しく動作しません。出力バッファは約 150 000 文字を超えると自動的にクリアされます。文字エンコーディングはシステムの OEM コードページに従います（例：CP866）。
- **グローバルホットキー**は修飾キーと 1 つの英字/数字の組み合わせです。別のプログラムがすでに同じ組み合わせを使っている場合、登録は失敗しバルーンチップで通知されます。
- **パネルサイズは起動のたびに「起動時サイズ」に戻ります** — 記憶されるのは位置だけです（仕様です）。
- **ドラッグ＆ドロップとタイルの移動には編集モードが必要です**（「アイコンの追加を許可」/ ✅ ボタン）。
- フォルダータイルは子アイコンを最大 **9** 個プレビュー表示します。フォルダーのポップアップは 1 行あたり最大 **4** 列です。
- パネルに追加した `.lnk`/`.ico` は **`ico\` にコピーされます**。元のファイルを移動しても壊れないようにするためです。
- **アーカイブを復元**は Tilettes が作成した zip のみを受け付けます（「今すぐバックアップ」/「バックアップを保存 (zip)」）。
- ウィンドウの角丸はリサイズ中は一時的に解除されます（ちらつき防止の手法）。マウスを離すと元に戻ります。
- レイアウト修正機能の対象は EN↔RU の QWERTY ペアのみです。その他のレイアウトはそのまま通されます。
- **シングルインスタンス**：2 つ目を起動しても既存のウィンドウが表示されるだけです。
- フォルダーの自動退出は「同じウィンドウ」モードでのみ、かつフォルダー内にいる間にのみ機能します。
- **写真/動画タイルのプレビュー**は Windows シェルのサムネイルキャッシュから取得されます。**追加したばかりの動画**には、エクスプローラーがプレビューを生成するまで汎用アイコンが表示されることがあります（ファイルのあるフォルダーをエクスプローラーで 1 度開いてください）。プレビューは一度表示されればアプリ独自のキャッシュに保持され、キャッシュからの追い出し後も残ります。プレビューがどうしても表示されない場合は、そのファイル用のコーデックがシステムに存在しないという意味です（例：拡張機能がインストールされていない HEVC）。

## ビルド

必要なのは .NET Framework 4.x を備えた Windows だけです（コンパイラは OS に同梱されています）：

```
build.bat          rem → Tilettes.exe (universal AnyCPU)
```

または直接：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /optimize+ /win32icon:app.ico /win32manifest:app.manifest /keyfile:Tilettes.snk /out:Tilettes.exe src\*.cs
```

リリースは `v*` タグごとに GitHub Actions が自動的に作成します：workflow は同じ csc の呼び出しで汎用 exe をビルドし、プレーンな exe ファイルを 1 つリリースに添付します（zip はありません）。加えて、そのチェックサムを含む `SHA256SUMS.txt` も添付されます（チェックサムはリリースノートにも追記されます）。GitHub による自動のソースコードアーカイブもリリース上にあります。汎用 AnyCPU ビルドは 64 ビット Windows では 64 ビットプロセスとして、32 ビット Windows では 32 ビットプロセスとして実行されます。exe は `build.bat` で自分でもビルドできます。

## ウイルス対策ソフトの誤検知

一部のウイルス対策製品は、`Tilettes.exe` に対して汎用的なヒューリスティック検知のフラグを立てることがあります（グローバルキーボードフックのインストール、`.lnk` ショートカットの解析、シェルアイコンの抽出を行う署名なしの小型ユーティリティは、ヒューリスティックが警戒するパターンに一致しやすいためです）。そのような検知は、そうでないことが証明されるまで**誤検知**として扱って構いません — しかも配布されているバイナリを信頼する必要はありません。すべて検証可能だからです：

- **ソースコードはこのリポジトリで完全に公開されています** — exe に入るすべての行がここにあります。
- **リリースは GitHub Actions によって自動的にビルドされます** — タグ付きコミットから、Microsoft 提供のランナー上で（`.github/workflows/build.yml`）。手作業でアップロードされるものは何もありません：リリースに添付された exe は、そのタグで見ることができるソースコードから正確にコンパイルされたものです。
- `build.bat` で **exe を自分でビルド**でき（C# コンパイラは Windows に同梱されています）、ダウンロードしたものの代わりに自分のビルドを実行できます。
- strong name キー（`Tilettes.snk`）はビルドのために生成されるだけです。strong name が証明するのはアセンブリの同一性であって、ベンダーの信頼ではありません — コードとビルドパイプラインを確認してください。
- v0.6.16 から、アプリは独自の更新確認において**リリースから 24 時間以内の新しいバージョンを提示しなくなりました**。そのため、公開直後の exe は、ウイルス対策ソフトのクラウド判定が落ち着くまでの最初の 1 日に広まることはありません。
