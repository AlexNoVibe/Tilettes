# Tilettes

[English](https://github.com/AlexNoVibe/Tilettes/blob/master/README.md) · [Русский](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.ru.md) · [Español](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.es.md) · [Português](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.pt.md) · [Deutsch](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.de.md) · [Français](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.fr.md) · [Italiano](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.it.md) · [Polski](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.pl.md) · [中文 (简体)](https://github.com/AlexNoVibe/Tilettes/blob/master/docs/README.zh.md) · **日本語**

Windows 用の高速起動パネル：ショートカット・フォルダー・タブをまとめたタイルグリッド、あいまい検索、コンソール内蔵のミニエクスプローラーを搭載。単一のポータブル EXE、インストール不要、.NET Framework 4.8 (WinForms)。

現在のバージョン：**v0.6.0-beta** — ダウンロード：[Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest) · [更新履歴](#changelog)。ステータス：**beta**。

## 特徴

- **パネル** — 1×1…6×6 のサイズのタイル、無制限のタブ（ドラッグ可能、複数行）、タブ内またはポップアップで開くフォルダー、エクスプローラーからのドラッグ＆ドロップ、カスタムグリッド（列数/行数/透明度）、アイコン倍率。
- **検索** — 名前、ファイル名、プログラムのメタデータ（FileDescription / ProductName / CompanyName）、フルパス、ユーザー説明を対象に検索。精度を調整できるあいまいマッチングと、誤ったキーボードレイアウトの修正（`руддщ` → `hello`）に対応。結果はマッチの品質でランク付けされ、一致した文字はハイライト表示されます。
- **ミニエクスプローラー** — パンくずナビゲーション、フォルダー/コマンド/グループのブックマーク、バックグラウンドインデックスによるファイル検索（現在のフォルダーまたはすべての固定ドライブ）、コマンド履歴・保存されたコマンド・Ctrl+ホイールでのフォント拡大に対応した内蔵 `cmd.exe` コンソール。
- **ファイルタイプルール** — 拡張子/マスクごとのアイコンと「アプリで開く」関連付け、インポート/エクスポート。
- **デスクトップ統合** — タスクトレイアイコン、Windows と共に自動起動、グローバルホットキー、エクスプローラー純正のコンテキストメニュー、縁のドラッグでリサイズできるボーダーレスウィンドウ。
- **初回起動と更新** — 一度だけ表示されるウェルカムウィンドウ（ベータに関する注意、言語選択、更新確認の許可、サンプルタイル）と、GitHub Releases に対する更新確認。新しいバージョンがあるときは隅にプレートが表示されます。

## 初回起動と更新

- **ウェルカムウィンドウ**（初回起動時のみ）：感謝のメッセージ、[Issues](https://github.com/AlexNoVibe/Tilettes/issues) へのリンク付きベータの注意書き、「ショートカットをドラッグ → タイルになる」という描画付きのミニ図解、言語選択（RU/EN の旗）、更新確認の許可、寄付用アドレス（クリックでコピー）— そして 2 つの終了ボタン：普通に**閉じる**、または**閉じてサンプルタイルを作成**（メモ帳・電卓・エクスプローラー・ペイントがすぐ使えるタイルとして登録されます）。設定の「ウェルカムウィンドウをもう一度表示」から、いつでも再表示できます。
- **更新確認** — アプリは公開の GitHub Releases API に N 日ごと（既定 3 日）問い合わせます（初回の確認も、最初の起動直後ではなく N 日後に行われます）。データは一切送信されず、設定で更新確認をオフにすればネットワークリクエストは一切発生しません。新しいタグが存在する場合、設定ボタンの横に緑色の **⟳ 更新** プレートが表示され、クリックすると [Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest) ページが開きます。設定の「今すぐ確認」は間隔に関係なく手動で確認を実行します（結果はメッセージボックスで通知されます）。自動インストールは現時点ではスタブ (TODO) です。
- **テスト用フック** — `WINPANEL_MOCK_UPDATE=0.6` を付けてアプリを起動すると、新しいリリースが存在する場合と同じように更新プレートが描画されます（ネットワーク通信なし）。

## 設定リファレンス

すべての設定は 1 つのダイアログ（⚙ ボタン / タスクトレイメニュー）にまとめられており、`settings.ini` に保存されます。

### 起動とウィンドウ

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| 起動時サイズ (W × H) | 200–4000 | 900 × 800 | 起動するたびのパネルサイズ。セッション中のリサイズは保存されません — 保存されるのは位置だけです。 |
| ウィンドウ位置 (X, Y) | −4000…4000 | 100, 100 | 起動時の画面上の位置。ウィンドウを移動すると自動的に更新されます。 |
| ウィンドウ表示ホットキー | プリセット + カスタム | Ctrl+Q | パネルの表示/アクティブ化を行うグローバルホットキー。プリセット（None、Ctrl+Q、Ctrl+Shift+Q、Alt+Q、Ctrl+J など）を選ぶか、編集可能なフィールドに任意の `Mod+Key` の組み合わせ（Ctrl/Alt/Shift/Win + 英字または数字）を直接入力できます。解釈できない入力は説明付きで拒否されます。 |
| 言語 | ru / en | ru | UI の言語。すぐに適用されます。 |

| グリッドの行数 | 1–100 | 16 | 垂直方向のセル数。 |

### 自動起動とタスクトレイ

| 設定 | 範囲 | 既定 | 説明 |
|---|---|---|---|
| Windows と共に自動起動 | オン/オフ | オフ | `HKCU\...\Run` に書き込みます（「Tilettes」）。 |
| 自動起動後はタスクトレイへ | オン/オフ | オフ | `--minimized` を付与：パネルはタスクトレイに隠れた状態で起動します。 |
| 閉じる代わりに最小化 | オン/オフ | オン | ✕ / Alt+F4 で終了せずにタスクトレイへ隠します（または最小化します）。終了はタスクトレイメニューから。 |
| タスクトレイアイコンを常に表示 | オン/オフ | オン | タスクトレイのアイコンが常に表示されます。 |
| アクティブなタブを記憶 | オン/オフ | オン | 起動時に最後にアクティブだったタブを復元します。 |

### バックアップとスタートメニュー同期

- **今すぐバックアップ** — `autoBackup\` への完全なバックアップ zip（設定、タイル、アイコン、ブックマーク、検索履歴、exe）。スケジュールは「N 日ごとにバックアップ」（0 = オフ）。期限が来ている場合は起動の約 3 分後に作成されます。
- **バックアップを保存 (zip)** — 同じアーカイブをユーザーが選んだファイルに保存します。
- **アーカイブを復元…** — Tilettes 自身が作成した zip のみを受け付けます。ファイルは作業フォルダーに展開され、`Tilettes.exe` が置き換えられることはありません。
- **スタートメニューを今すぐ同期** / N 時間ごと (0 = オフ) — ミラーされたスタートメニュータブを再構築します。

### コンソール

1 行の `cmd.exe` コマンドなら何でも入力して実行できます（Enter または**実行**ボタン）。作業ディレクトリはコマンドごとに現在のフォルダーへ再同期されます。**+ 保存**は入力したコマンドをブックマークとして保存し（グループ内にも保存可能）、保存されたコマンドはクリックで実行できます。ボタン：**クリア**（出力の消去）、**再起動**（新しい cmd.exe）、**新しいウィンドウ**（現在のフォルダーで本物のコンソールウィンドウを開く）。コマンド履歴はセッション中であれば ↑ / ↓ でたどれます。

## 制限事項

- **Windows + .NET Framework 4.8 専用**（GDI/WinForms）。モニターごとの DPI 認識には対応していません — 高倍率のスケーリングが設定されたディスプレイでは UI がにじむことがあります。
- **「すべて」の検索スコープ**は**ローカルの固定ドライブのみ**をインデックス化します（USB/ネットワークドライブは対象外）。ドライブあたり **200,000 件**が上限です。インデックス化はバックグラウンドで行われるため、動作中は結果が徐々に増えていきます（ステータス行に「インデックス化中: N」と表示）。
- **パネル検索**は上位 **200** 件を表示し、**ミニエクスプローラー検索**は最大 **400** 件を返します。ファイルリストは 1 ディレクトリあたり最大 **800** 件です。
- **コンソールは `cmd.exe` のみ**：コマンドは 1 行のみ。対話型/TUI プログラム（エディターやキー入力を受け付けるページャーなど）は正しく動作しません。出力バッファは約 150,000 文字を超えると自動的にクリアされます。文字エンコーディングはシステムの OEM コードページに従います（例：CP866）。
- **グローバルホットキー**は修飾キーと 1 つの英字/数字の組み合わせです。別のプログラムがすでに同じ組み合わせを使っている場合、登録は失敗しバルーンチップで通知されます。
- **パネルサイズは起動のたびに「起動時サイズ」に戻ります** — 記憶されるのは位置だけです（仕様です）。
- **ドラッグ＆ドロップとタイルの移動には編集モードが必要です**（「アイコンの追加を許可」/ ✅ ボタン）。
- フォルダータイルは子アイコンを最大 **9** 個プレビュー表示します。フォルダーのポップアップは 1 行あたり最大 **4** 列です。
- パネルに追加した `.lnk`/`.ico` は **`ico\` にコピーされます**。元のファイルを移動しても壊れないようにするためです。
- **アーカイブを復元**は Tilettes が作成した zip のみを受け付けます（「今すぐバックアップ」/「バックアップを保存 (zip)」）。
- ウィンドウの角丸はリサイズ中は一時的に解除されます（ちらつき防止の手法）。マウスを離すと元に戻ります。
- レイアウト修正機能の対象は EN↔RU の QWERTY ペアのみです。その他のレイアウトはそのまま通されます。
- **シングルインスタンス**：2 つ目を起動しても既存のウィンドウが表示されるだけです。
- フォルダーの自動退出は「同じウィンドウ」モードでのみ、かつフォルダー内にいる間にのみ機能します。

## ビルド

必要なのは .NET Framework 4.x を備えた Windows だけです（コンパイラは OS に同梱されています）：

```
build.bat
```

または直接：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /win32icon:app.ico /out:Tilettes.exe src\*.cs
```

リリースは `v*` タグごとに GitHub Actions が自動的に作成します：workflow は同じ csc の呼び出しで exe の各バリアントをビルドし、プレーンな exe ファイルをリリースに添付します（AnyCPU 汎用 + x86 + x64 — zip はありません）。GitHub による自動のソースコードアーカイブもリリース上にあります。exe は `build.bat` で自分でもビルドできます。

## 更新履歴

### v0.6.0-beta (2026-10-01)

- パフォーマンス：起動の高速化（タブの遅延レンダリング — 構築されるのはアクティブなタブのみ）、永続的なアイコンキャッシュ（シェルアイコンはタイルの生存期間中に 1 回だけ抽出）、検索メタデータはアイテムの追加時に 1 回だけ収集。ミニエクスプローラーの検索フィールドは無効化されています（コードは再有効化のために保持）。
- ネットワーク共有が UI スレッドをブロックすることはありません：ネットワークパス上のアイコンや .lnk のリンク先はバックグラウンドで解決されます。
- アクティブなスキンがライト/ダークのパレットをすべての場面で決定するようになりました（Mint を選んでもダークなウィンドウが残りません）。Mint が既定のテーマとなり、すべてのフォントの既定値は 14 です。
- 初回起動：作業領域が 900px 未満のモニターでは、既定のウィンドウとグリッドが画面に収まるよう比例して縮小されます。
- 強化：strong name、VERSIONINFO、明示的なマニフェスト。Win キーのキャプチャはオプトイン — VirusTotal で 0 検出。
- リリースアセットは zip アーカイブの代わりに CPU ごとのプレーンな exe ファイル（AnyCPU/x86/x64）。リリースノートは CHANGELOG.md から取得されます。

### v0.5 (2026-09-30)

- 初回起動のウェルカムウィンドウ（データフォルダーごとに 1 回）：感謝のメッセージ、ベータのお知らせ + issue へのリンク、描画付きミニ図解、言語選択（RU/EN の旗）、更新確認の許可、寄付用アドレス（クリックでコピー）。終了は「閉じる」または「閉じてサンプルタイルを作成」（メモ帳 / 電卓 / エクスプローラー / ペイントがすぐ使えるタイルとして）。設定から再度表示できます。
- 更新確認：アプリは公開の GitHub Releases API に最新タグを N 日ごと（既定 3 日。初回の確認もインストールの N 日後）に問い合わせます — ユーザーが許可した場合にのみ実行され、それ以外ではネットワークリクエストはゼロです。新しいバージョンが存在する場合、設定ボタンの横に緑色の「更新」プレートが表示され、リリースページを開きます。設定には手動の「今すぐ確認」ボタンがあります（結果はメッセージボックスで報告されます）。自動インストールはスタブ (TODO)。プレートをテストするためのモックフック：`WINPANEL_MOCK_UPDATE=0.6`。
- 設定：新しい「更新」セクション（確認のトグル、日数での間隔、「今すぐ確認」ボタン、自動インストールのスタブ、ポップアップウォレットメニュー付きの寄付行 — クリックでアドレスをコピー — ウェルカムウィンドウの再表示ボタン）。編集可能なホットキーフィールド：Ctrl/Alt/Shift/Win + 英字/数字の任意の組み合わせを入力できます（検証付き）。既定値は Ctrl+Q に変更されました。
- プログラムの UI を **10 言語**にローカライズ：英語（ソース）、ロシア語、スペイン語、ポルトガル語、ドイツ語、フランス語、イタリア語、ポーランド語、中国語（簡体字）、日本語。言語は設定またはウェルカムウィンドウの描画された旗で選択します。新しい言語の追加はテーブルファイル 1 つ + 1 行です（loc.cs を参照）。
- チェーンごとにグループ化された実際の寄付ウォレット一覧：EVM ネットワーク（ETH · Polygon · Base · Monad · HyperEVM）は 1 つのアドレスを共有。加えて Bitcoin、Solana、Sui。
- バージョンは単一の定数になりました（`AppInfo.AppVersion`）。タスクトレイのツールチップとウェルカムウィンドウに表示されます。
- GitHub インフラ：MIT ライセンス、FUNDING.yml（ウォレットのアンカーへのスポンサーリンク）、拡張しやすいよう言語ごとのファイルに分割された README（`README.md` 英語 + 9 つの翻訳）、GitHub Actions workflow（`v*` タグでポータブル zip のリリース）、GitHub Pages 用の docs ランディングページ。履歴上のすべてのコミットメッセージは英語です。
