Tilettes

v0.5
beta

A fast-launch panel for Windows: a tile grid with shortcuts, folders and tabs, built-in fuzzy search and a mini explorer with an embedded console. One portable EXE, no installer, .NET Framework 4.8 (WinForms).

Download GitHub · README Issues

Highlights

  • Just drag a shortcut or a file onto the panel — it becomes a tile.
  • Fuzzy search across names, metadata, paths and descriptions (fixes the wrong keyboard layout: руддщ → hello).
  • Folders, tabs, custom grid, icon scaling, dark/light themes and skins.
  • Mini explorer with bookmarks and a working cmd.exe console.
  • First-start welcome window and an update check against GitHub Releases.

Панель быстрого запуска для Windows: сетка плиток с ярлыками, папками и вкладками, встроенный fuzzy-поиск и мини-проводник с консолью. Один портативный EXE, без установки, .NET Framework 4.8 (WinForms).

Коротко

  • Просто перетащите ярлык или файл на панель — появится плитка.
  • Fuzzy-поиск по именам, метаданным, путям и описаниям (чинит неверную раскладку: руддщ → hello).
  • Папки, вкладки, своя сетка, масштаб иконок, тёмная/светлая темы и шкурки.
  • Мини-проводник с закладками и рабочей консолью cmd.exe.
  • Приветственное окно при первом старте и проверка обновлений через GitHub Releases.
