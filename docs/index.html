A fast-launch panel for Windows: a tile grid with shortcuts, folders and tabs, built-in fuzzy search and a mini explorer with an embedded console. One portable EXE, no installer, .NET Framework 4.8 (WinForms).

Download GitHub · README Issues

Highlights

  • Tiles 1×1…6×6, unlimited draggable tabs, folders in-tab or as popups, scrollable extra rows, multi-select editing, drag-and-drop — plus skins (Mint, Night, Android), light/dark themes, custom fonts.
  • A custom name, description (searchable) and icon for every tile; photo/video previews right on the tiles.
  • Instant fuzzy search over names, program metadata, full paths and descriptions — runs on cached metadata, no disk scans; wrong layout fixed (руддщ → python); past queries remembered between sessions.
  • One ~0.5 MB portable exe, ~30 MB of RAM, no dependencies beyond the .NET Framework built into Windows; icons cached once per tile lifetime; launches never block the panel.
  • Mini explorer: breadcrumbs, bookmarks and an embedded cmd.exe console; favorite commands in one click, %1 = current folder (wt -d "%1").
  • Per-file-type icons and "open with" rules, import/export.
  • Mirrored Start Menu tab (UWP/Store apps included), synced on a schedule — searchable.
  • Global hotkey, optional Win-key capture, tray, autostart, native Explorer menus, scheduled and manual backups; UI in 10 languages.
  • Open source, built by GitHub Actions with SHA256SUMS; the only network call is the opt-in update check — no telemetry.

Панель быстрого запуска для Windows: сетка плиток с ярлыками, папками и вкладками, встроенный fuzzy-поиск и мини-проводник с консолью. Один портативный EXE, без установки, .NET Framework 4.8 (WinForms).

Коротко

  • Плитки 1×1…6×6, неограниченные перетаскиваемые вкладки, папки внутри вкладки или попапом, прокручиваемые доп. ряды, мультивыделение, drag-and-drop — плюс шкурки (Мята, Ночь, Android), светлые/тёмные темы, свои шрифты.
  • Каждой плитке — своё название, описание (участвует в поиске) и иконка; фото и видео — превью прямо на плитке.
  • Мгновенный fuzzy-поиск по именам, метаданным программ, путям и описаниям — по кэшу метаданных, без обхода дисков; чинит раскладку (руддщ → hello); прошлые запросы помнятся между сессиями.
  • Один портативный exe ~0.5 МБ, ~30 МБ памяти, ноль зависимостей — только встроенный в Windows .NET Framework; иконки кэшируются один раз за жизнь плитки; запуски не блокируют панель.
  • Мини-проводник: хлебные крошки, закладки и встроенная консоль cmd.exe; избранные команды кликом, %1 = текущая папка (wt -d "%1").
  • Правила типов файлов: своя иконка и «открывать через», импорт/экспорт.
  • Зеркальная вкладка Пуска (включая UWP/Store) с синхронизацией по расписанию — работает в поиске.
  • Глобальная горячая клавиша, опциональный захват Win, трей, автозапуск, родные меню Проводника, бэкапы по расписанию и вручную; 10 языков интерфейса.
  • Открытый код, сборка GitHub Actions + SHA256SUMS; единственный сетевой запрос — проверка обновлений по согласию; никакой телеметрии.
