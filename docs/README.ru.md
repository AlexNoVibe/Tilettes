Панель быстрого запуска для Windows: сетка плиток с ярлыками, папками и вкладками, встроенный fuzzy-поиск и мини-проводник с консолью. Один портативный EXE, без установки, .NET Framework 4.8 (WinForms).

Текущая версия: **v0.5** — загрузка: [Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest) · [Ченжлог](#чangelog). Статус: **бета**.

## Возможности

- **Панель** — плитки 1×1…6×6, неограниченные вкладки (перетаскиваются, в несколько рядов), папки внутри вкладки или всплывающим окном, drag-and-drop из Проводника, настраиваемая сетка (колонки/строки/прозрачность), масштаб иконок.
- **Поиск** — по именам, именам файлов, метаданным программ (FileDescription / ProductName / CompanyName), полным путям и пользовательским описаниям; fuzzy-поиск с настраиваемой точностью и исправлением неверной раскладки (`руддщ` → `hello`); результаты ранжируются по качеству совпадения, совпавшие символы подсвечиваются.
- **Мини-проводник** — навигация по «хлебным крошкам», закладки (папки / команды / группы), поиск файлов (текущая папка или все диски) с фоновым индексом, встроенная консоль `cmd.exe` с историей команд, сохранёнными командами и зумом шрифта Ctrl+колесом.
- **Правила типов файлов** — иконки и «открывать через» по расширению или маске, импорт/экспорт.
- **Интеграция с системой** — значок в трее, автозапуск с Windows, глобальная горячая клавиша, системные контекстные меню Проводника, безрамочное окно с ресайзом за края.
- **Первый запуск и обновления** — одноразовое приветственное окно (о бете, выбор языка, разрешение на проверку обновлений, примеры плиток) и проверка обновлений через GitHub Releases с плашкой в углу при новой версии.

## Первый запуск и обновления

- **Приветственное окно** (только при самом первом запуске): благодарность, предупреждение о бете со ссылкой на [Issues](https://github.com/AlexNoVibe/Tilettes/issues), нарисованная мини-диаграмма «перетащите ярлык → появится плитка», выбор языка (флажки RU/EN), разрешение на проверку обновлений, адреса для доната (клик — копировать) — и две кнопки выхода: просто **Закрыть** или **Закрыть и создать примеры** (Блокнот, Калькулятор, Проводник, Paint готовыми плитками). Вызвать снова можно кнопкой «Показать приветственное окно» в настройках.
- **Проверка обновлений** — приложение спрашивает публичный GitHub Releases API раз в N дней (по умолчанию 3; первая проверка тоже происходит через N дней после самой первой установки, а не сразу). Никуда ничего не отправляется, а при выключенной галочке сетевой запрос не делается вообще. Если есть более новая версия, в углу у кнопки настроек появляется зелёная плашка **⟳ Обновить** и открывает страницу [Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest). Кнопка «Проверить сейчас» в настройках делает ручную проверку независимо от интервала (результат — в сообщении). Автоустановка пока заглушка (TODO).
- **Тестовый крючок** — запуск с `WINPANEL_MOCK_UPDATE=0.6` рисует плашку «Обновить», как будто вышла версия 0.6 (без сети).

### Бэкап и синхронизация Пуска

- **Бэкап сейчас** — полный zip-бэкап в `autoBackup\` (настройки, плитки, значки, закладки, история поиска, exe); расписание — «Бэкап раз в N дней» (0 = выкл), создаётся через ~3 минуты после запуска, когда подошёл срок.
- **Сохранить бэкап (zip)** — тот же архив в выбранный файл.
- **Восстановить из архива…** — ожидает zip, созданный самими Плиточками; файлы распаковываются в рабочую папку, `Tilettes.exe` не заменяется.
- **Синхронизировать Пуск** сейчас / раз в N часов (0 = выкл) — перестраивает зеркальную вкладку Пуск.

### Консоль

Любую однострочную команду `cmd.exe` можно ввести и выполнить (Enter или кнопка **Выполнить**). Перед каждой командой рабочая папка синхронизируется с текущей. **+ Команда** сохраняет введённую команду закладкой (опционально в группу); сохранённые команды запускаются кликом. Кнопки: **Очистить** (стереть вывод), **Перезапуск** (новый cmd.exe), **Новое окно** (настоящее окно консоли в текущей папке). История команд доступна по ↑ / ↓ в течение сессии.

## Ограничения

- **Только Windows + .NET Framework 4.8** (GDI/WinForms). Нет per-monitor DPI — на сильно масштабированных экранах интерфейс может быть слегка размытым.
- **Область «Везде»** индексирует **только локальные фиксированные диски** (USB/сеть не входят), лимит **200 000 объектов на диск**; индекс строится в фоне — результаты пополняются по мере работы (в строке статуса видно «индексация: N»).
- **Поиск по панели** показывает лучшие **200** совпадений; **поиск мини-проводника** — до **400**; в списке файлов — максимум **800** записей на папку.
- **Консоль — только `cmd.exe`**: однострочные команды; интерактивные/TUI-программы (редакторы, пейджеры с вводом с клавиатуры) корректно не работают; буфер вывода автоматически очищается после ~150 000 символов; кодировка — системная OEM (например, CP866).
- **Глобальная горячая клавиша** — одна буква/цифра плюс модификаторы; если комбинация уже занята другой программой, регистрация не удастся (появится всплывающее уведомление).
- **Размер панели сбрасывается к «Размеру при запуске» при каждом старте** — запоминается только позиция (сделано намеренно).
- **Перетаскивание плиток и приём файлов требуют режима редактирования** («Разрешать добавлять значки» / кнопка ✅).
- Плитка папки показывает не более **9** мини-иконок; попап папки — не более **4** колонок в ряду.
- Добавленные на панель `.lnk`/`.ico` **копируются в `ico\`**, чтобы не терялись при перемещении оригиналов.
- **Восстановление из архива** принимает только zip, созданные Плиточками («Бэкап сейчас» / «Сохранить бэкап (zip)»).
- Скруглённые углы окна временно отключаются при ресайзе (техника против мерцания) и возвращаются после.
- Исправление раскладки работает для пары EN↔RU (QWERTY/ЙЦУКЕН); другие раскладки проходят без изменений.
- **Один экземпляр**: повторный запуск просто показывает уже открытое окно.
- Авто-выход из папки по простою работает только в режиме «В этом же окне» и только находясь внутри папки.

## Сборка

Нужна любая Windows с .NET Framework 4.x (компилятор входит в состав системы):

```
build.bat
```

или напрямую:

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /win32icon:app.ico /out:Tilettes.exe src\*.cs
```

Релизы создаются автоматически GitHub Actions по каждому тегу `v*`: workflow проверяет сборку и прикрепляет портативный zip (Tilettes.exe + README + LICENSE); автоматические архивы исходников тоже на месте. exe можно собрать и самому через `build.bat`.

## Ченжлог / Changelog

### v0.5 (2026-09-30)

- Приветственное окно при первом запуске (один раз на папку данных): благодарность, о бете + ссылка на issue, нарисованная мини-диаграмма, выбор языка (флажки RU/EN), разрешение на проверку обновлений, адреса доната (клик — копировать); выход — «Закрыть» или «Закрыть и создать примеры» (Блокнот / Калькулятор / Проводник / Paint готовыми плитками). Вызывается снова из настроек.
- Проверка обновлений: приложение спрашивает публичный GitHub Releases API о свежем теге раз в N дней (по умолчанию 3; первая проверка — тоже через N дней после установки) — строго только с согласия пользователя, иначе ноль сетевых запросов. При новой версии в углу появляется зелёная плашка «Обновить», открывающая страницу релизов. Кнопка «Проверить сейчас» в настройках делает ручную проверку (результат — в сообщении). Автоустановка — заглушка (TODO). Тестовый крючок для плашки: `WINPANEL_MOCK_UPDATE=0.6`.
- Настройки: новая секция «Обновления» (галочка проверки, интервал в днях, «Проверить сейчас», автоустановка-заглушка, строка доната с всплывающим меню кошельков — клик копирует адрес — и кнопка повторного вызова приветственного окна). Редактируемое поле горячей клавиши: любая комбинация Ctrl/Alt/Shift/Win + буква/цифра (с валидацией), по умолчанию — Ctrl+Q.
- Интерфейс программы переведён на **10 языков**: английский (источник), русский, испанский, португальский, немецкий, французский, итальянский, польский, китайский (упрощённый) и японский. Язык выбирается в настройках или флажками в приветственном окне; новый язык = один файл-таблица + одна строка (см. loc.cs).
- Реальный список кошельков, сгруппированный по цепочкам: EVM-сети (ETH · Polygon · Base · Monad · HyperEVM) — один адрес; плюс Bitcoin, Solana и Sui.
- Версия — теперь одна константа (`AppInfo.AppVersion`); показывается в подсказке трея и в приветственном окне.
- GitHub-инфраструктура: лицензия MIT, FUNDING.yml (ссылки спонсора на якоря кошельков), README разбит на файлы по языкам (`README.md` EN + 9 переводов) для лёгкого расширения, workflow GitHub Actions (релиз с портативным zip по тегам `v*`), лендинг для GitHub Pages в docs/. Все сообщения коммитов в истории — на английском.
