Панель быстрого запуска для Windows: сетка плиток с ярлыками, папками и вкладками, встроенный fuzzy-поиск и мини-проводник с консолью. Один портативный EXE, без установки, .NET Framework 4.8 (WinForms).

![Плиточки — главное окно](screenshot_main.png)

Текущая версия: **v1.0** — загрузка: [Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest) · [Ченжлог](#чangelog). Статус: **бета**.

## Фишки

**Плитки и вкладки** — плитки 1×1…6×6; шкурки (Мята, Ночь, Android) плюс светлые/тёмные темы; свои шрифты и цвета; неограниченные перетаскиваемые вкладки в несколько рядов, свободный/сеточный режим; папки внутри вкладки или всплывающим окном; прокручиваемые дополнительные ряды ниже сетки; режим редактирования с мультивыделением и drag-and-drop; каждой плитке — своё название, описание (участвует в поиске) и иконка; фото и видео видны на плитках превью.

**Поиск** — мгновенный fuzzy-поиск по именам, метаданным программ (описание / продукт / компания), полным путям и своим описаниям; работает по кэшу метаданных (без обхода дисков); чинит неверную раскладку (`знерщи` → `python`); выдача в два блока — прошлые запросы (с настоящими иконками, помнятся между сессиями, с бустом) сверху, обычные результаты снизу; каждый источник включается отдельно.

**Лёгкость** — один портативный exe ~0.5 МБ (517 КБ), все данные рядом с ним; никаких зависимостей — только .NET Framework, уже встроенный в Windows; ~30 МБ памяти; иконка извлекается из системы ровно один раз за жизнь плитки в самоочищающийся `iconcache\`; запуски никогда не блокируют панель (отсоединённые процессы, сетевые пути в фоне); при старте строится только активная вкладка.

**Мини-проводник** — хлебные крошки, закладки папок/команд/групп, встроенная консоль `cmd.exe` (история, шрифт Ctrl+колесом); избранные команды запускаются кликом, `%1` = текущая папка (`wt -d "%1"`); правила «открывать через» по расширению/маске с импортом/экспортом.

**Система** — зеркальная вкладка Пуска (включая UWP/Store) с синхронизацией по расписанию; глобальная горячая клавиша, опциональный захват Win, трей, автозапуск; родные контекстные меню Проводника; бэкапы по расписанию и вручную с восстановлением в клик; интерфейс на 10 языках.

**Открытый код** — исходники полностью открыты; релизы собирает GitHub Actions ровно из тега + SHA256SUMS.txt; единственный сетевой запрос во всей программе — проверка обновлений по согласию; никакой телеметрии.

## Возможности

- **Панель** — плитки 1×1…6×6, неограниченные вкладки (перетаскиваются, в несколько рядов), папки внутри вкладки или всплывающим окном, drag-and-drop из Проводника, настраиваемая сетка (колонки/строки/прозрачность), масштаб иконок.
- **Поиск** — по именам, именам файлов, метаданным программ (FileDescription / ProductName / CompanyName), полным путям и пользовательским описаниям; опционально включает зеркальную вкладку Пуска; fuzzy-поиск с настраиваемой точностью и исправлением неверной раскладки (`руддщ` → `hello`); результаты ранжируются по качеству совпадения, совпавшие символы подсвечиваются; повторные запросы получают буст истории; введённый запрос делит результаты на два блока — запомненные прошлые запросы сверху, обычные результаты снизу (полные дубликаты схлопываются); в строках прошлых запросов рисуются настоящие иконки запомненных элементов.
- **Мини-проводник** — навигация по «хлебным крошкам», закладки папок/команд/групп (команда может содержать `%1` — подставляется текущая просматриваемая папка, например `wt -d "%1"` открывает Windows Terminal прямо в ней), встроенная консоль `cmd.exe` с историей команд, сохранёнными командами и зумом шрифта Ctrl+колесом. (Поиск файлов отключён с v0.6.0-beta — заглушка сохранена на будущее.)
- **Правила типов файлов** — иконки и «открывать через» по расширению или маске, импорт/экспорт.
- **Интеграция с системой** — значок в трее, автозапуск с Windows, глобальная горячая клавиша, опциональный захват клавиши Win, системные контекстные меню Проводника, безрамочное окно с ресайзом за края.
- **Шкурки и мелочи** — декоративные шкурки (своя палитра + скруглённая рамка окна), зеркальная вкладка Пуска, перестраиваемая по расписанию, полные бэкапы в `autoBackup\`, история поиска по панели.
- **Первый запуск и обновления** — одноразовое приветственное окно (нарисованная диаграмма «три источника → сетка плиток», выбор языка, разрешение на проверку обновлений, ссылка на поддержку, примеры плиток) и проверка обновлений через GitHub Releases с плашкой в углу при новой версии.

## Первый запуск и обновления

- **Приветственное окно** (только при самом первом запуске): благодарность, пометка «возможны баги и недоделки» со ссылкой на [Issues](https://github.com/AlexNoVibe/Tilettes/issues), нарисованная мини-диаграмма (карточки папки, .exe и .lnk → стрелка → сетка плиток с призрачной ячейкой «+»), выбор языка (10 флажков), разрешение на проверку обновлений, блок **Поддержать автора** со ссылкой на [раздел доната](https://github.com/AlexNoVibe/Tilettes#донат) — и две кнопки выхода: просто **Закрыть** или **Закрыть и создать примеры** (Блокнот, Калькулятор, Проводник, Paint готовыми плитками). Вызвать снова можно кнопкой «Показать приветственное окно» в настройках.
- **Проверка обновлений** — приложение спрашивает публичный GitHub Releases API раз в N дней (по умолчанию 3; первая проверка тоже происходит через N дней после самой первой установки, а не сразу). Никуда ничего не отправляется, а при выключенной галочке сетевой запрос не делается вообще. Если есть более новая версия, в углу у кнопки настроек появляется зелёная плашка **⟳ Обновить** и открывает страницу [Releases](https://github.com/AlexNoVibe/Tilettes/releases/latest). Кнопка «Проверить сейчас» в настройках делает ручную проверку независимо от интервала (результат — в сообщении). Автоустановка пока заглушка (TODO).
- **Тестовый крючок** — запуск с `WINPANEL_MOCK_UPDATE=0.6` рисует плашку «Обновить», как будто вышла версия 0.6 (без сети).

Все настройки — в одном окне (кнопка ⚙ / меню трея), хранятся в `settings.ini`.

| Позиция окна (X, Y) | −4000…4000 | 100, 100 | Позиция на экране при запуске. Обновляется автоматически при перемещении окна. |

### Бэкап и синхронизация Пуска

- **Бэкап сейчас** — полный zip-бэкап в `autoBackup\` (настройки, плитки, значки, закладки, история поиска, exe); расписание — «Бэкап раз в N дней» (по умолчанию 7, 0 = выкл), создаётся через ~3 минуты после запуска, когда подошёл срок.
- **Сохранить бэкап (zip)** — тот же архив в выбранный файл.
- **Восстановить из архива…** — ожидает zip, созданный самими Плиточками; файлы распаковываются в рабочую папку, `Tilettes.exe` не заменяется.
- **Синхронизировать Пуск** сейчас / раз в N часов (по умолчанию 24, 0 = выкл) — перестраивает зеркальную вкладку Пуск.

### Основная панель

| Клавиши / действие | Результат |
|---|---|
| Горячая клавиша (по умолчанию Ctrl+Q) | Показать / активировать панель. |
| Одиночное нажатие Win (опция) | Показать / скрыть панель вместо меню Пуска — включите «Захват кнопки Пуск (Win)» в настройках. |
| Просто начните печатать, или Ctrl+F | Открыть поиск по панели. |
| ↓ | Перейти к списку результатов. |
| Enter | Открыть выбранный результат (папка — перейти, файл — запустить). |
| Esc | Закрыть поиск. |
| Клик по плитке | Запуск элемента; папка открывается (или попап — по настройке). |
| Ctrl+клик по плитке папки | Открыть мини-проводник (если включён). |
| Перетаскивание плитки (режим редактирования) | Переместить; бросить на папку — переместится внутрь. |

| ПКМ по вкладке | Удалить (последнюю нельзя), Переименовать, Переключить свободная/сетка. |

### Консоль

Любую однострочную команду `cmd.exe` можно ввести и выполнить (Enter или кнопка **Выполнить**). Перед каждой командой рабочая папка синхронизируется с текущей. **+ Команда** сохраняет введённую команду закладкой (опционально в группу); сохранённые команды запускаются кликом, и команда может содержать `%1` — текущую просматриваемую папку (заводская группа CMD по умолчанию несёт закладку `wt -d "%1"` для открытия Windows Terminal прямо в папке). Кнопки: **Очистить** (стереть вывод), **Перезапуск** (новый cmd.exe), **Новое окно** (настоящее окно консоли в текущей папке). История команд доступна по ↑ / ↓ в течение сессии.

## Ограничения

- **Только Windows + .NET Framework 4.8** (GDI/WinForms). Нет per-monitor DPI — на сильно масштабированных экранах интерфейс может быть слегка размытым.
- **Поиск файлов в мини-проводнике отключён** с v0.6.0-beta: модуль индексации дисков (только локальные фиксированные диски, лимит 200 000 объектов на диск) сохранён как заглушка на будущее. Поиск по панели работает по кэшированным метаданным сохранённых элементов — без индексации дисков.
- **Поиск по панели** показывает лучшие **200** совпадений; в списке файлов — максимум **800** записей на папку.
- **Консоль — только `cmd.exe`**: однострочные команды; интерактивные/TUI-программы (редакторы, пейджеры с вводом с клавиатуры) корректно не работают; буфер вывода автоматически очищается после ~150 000 символов; кодировка — системная OEM (например, CP866).
- **Глобальная горячая клавиша** — одна буква/цифра плюс модификаторы; если комбинация уже занята другой программой, регистрация не удастся (появится всплывающее уведомление).
- **Размер панели сбрасывается к «Размеру при запуске» при каждом старте** — запоминается только позиция (сделано намеренно).
- **Перетаскивание плиток и приём файлов требуют режима редактирования** («Разрешать добавлять значки» / кнопка ✅).
- Плитка папки показывает не более **9** мини-иконок; попап папки — не более **4** колонок в ряду.
- Добавленные на панель `.lnk`/`.ico` **копируются в `ico\`**, чтобы не терялись при перемещении оригиналов.
- **Восстановление из архива** принимает только zip, созданные Плиточками («Бэкап сейчас» / «Сохранить бэкап (zip)»).
- Скруглённые углы окна временно отключаются при ресайзе (техника против мерцания) и возвращаются после.
- Исправление раскладки работает для пары EN↔RU (QWERTY/ЙЦУКЕН); другие раскладки проходят без изменений.
- **Один экземпляр**: повторный запуск просто показывает уже открытое окно.
- Авто-выход из папки по простою работает только в режиме «В этом же окне» и только находясь внутри папки.
- **Превью фото/видео на плитках** берутся из системного кэша миниатюр Windows. **Свежедобавленное видео** может показывать общую иконку, пока Проводник не сгенерирует превью (откройте один раз папку с файлом в Проводнике). Полученное превью хранится в собственном кэше приложения и переживает очистку кэша; если превью так и не появилось — в системе нет кодека для этого файла (например, HEVC без расширения).

## Сборка

Нужна любая Windows с .NET Framework 4.x (компилятор входит в состав системы):

```
build.bat          rem → Tilettes.exe (универсальный AnyCPU)
build.bat x86      rem → Tilettes-x86.exe
build.bat x64      rem → Tilettes-x64.exe
```

или напрямую:

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /optimize+ /win32icon:app.ico /win32manifest:app.manifest /keyfile:Tilettes.snk /out:Tilettes.exe src\*.cs
```

Релизы создаются автоматически GitHub Actions по каждому тегу `v*`: workflow собирает варианты exe тем же вызовом csc и прикрепляет к релизу обычные exe-файлы (AnyCPU-универсальный + x86 + x64 — без zip), а также `SHA256SUMS.txt` с контрольными суммами всех трёх exe (суммы добавляются и в заметки релиза); автоматические архивы исходников GitHub тоже на месте. exe можно собрать и самому через `build.bat`.

## False positive антивирусов

Некоторые антивирусы иногда помечают `Tilettes.exe` generic-эвристикой (небольшие неподписанные утилиты с глобальным хуком клавиатуры, разбором `.lnk`-ярлыков и извлечением иконок из shell — типичный профиль для эвристик). До доказательства обратного это **false positive**, и верить бинарнику на слово не нужно — всё проверяемо:

- **Исходный код полностью открыт** в этом репозитории — каждая строка, попадающая в exe, находится здесь.
- **Релизы собираются автоматически GitHub Actions** из тегированного коммита на раннерах Microsoft (`.github/workflows/build.yml`). Ничего не загружается вручную: exe в релизе скомпилирован ровно из тех исходников, которые видны по этому тегу.
- Можно **собрать exe самостоятельно** через `build.bat` (компилятор C# входит в состав Windows) и пользоваться своей сборкой вместо скачанной.
- Ключ сильного имени (`Tilettes.snk`) сгенерирован только для сборки; strong name доказывает идентичность сборки, а не доверие вендора — смотрите код и пайплайн сборки.
- С v0.6.16 приложение также **не предлагает релизы моложе 24 часов** (собственная проверка обновлений): свежеопубликованный exe не расходится в первые сутки, пока устаканиваются облачные вердикты антивирусов.
