# WinPanel

Лаунчер-панель быстрого запуска для Windows: сетка плиток с ярлыками, папками и вкладками, встроенный поиск по сохранённым элементам и мини-проводник с консолью. Один exe-файл, без установки — .NET Framework 4.8 (WinForms).

## Возможности

### Панель запуска
- Плитки 1x1–4x4, несколько вкладок (перетаскиваются, в том числе между рядами).
- Папки: открываются внутри вкладки или всплывающим окном; элементы внутри папок перетаскиваются, выносятся наружу.
- Режим редактирования (кнопка ✅): перетаскивание, создание папок, приём файлов drag-and-drop из Проводника.
- Настраиваемая сетка (колонки/строки/прозрачность), масштаб иконок.
- Контекстные меню элементов + системное меню Проводника (открыть содержащую папку и т.д.).
- Описание у любого элемента: всплывает подсказкой при наведении и участвует в поиске.
- Сворачивание в трей, автозапуск с Windows, «показать окно» по горячей клавише (по умолчанию Ctrl+J).
- Окно без рамки: перетаскивание за верхнюю полосу, ресайз с любого края и угла.

### Поиск
- Панельный поиск (Ctrl+F или просто начните печатать): по имени, имени файла, метаданным программы (FileDescription, ProductName, CompanyName), полным путям и пользовательским описаниям — каждая область включается отдельно в настройках.
- Fuzzy-поиск с настраиваемой точностью (0–3) и исправлением неправильной раскладки клавиатуры («руддщ» → «hello»).
- Результаты ранжируются по качеству совпадения: имя > имя файла > описание > папки > путь; подсвечиваются совпавшие символы.
- Формат строки результата: иконка и имя слева, описание в середине, полный путь справа (длинный путь обрезается до хвоста; при наведении — подсказка с полным путём).

### Мини-проводник
- Открывается из меню папки или Ctrl+кликом по плитке папки.
- Хлебные крошки с редактированием пути (Ctrl+L), навигация назад/вперёд/вверх, F5.
- Закладки: папки, группы и консольные команды; боковая панель и верхняя полоса; команды можно редактировать и перемещать.
- Поиск файлов (текущая папка или все диски) с индексацией в фоне, fuzzy и подсветкой совпадений.
- Встроенная консоль: вывод cmd в окно, история команд по стрелкам, размер шрифта — Ctrl+колесо мыши (сохраняется), высота консоли тянется сплиттером.
- Один клик — «Открыть окно консоли здесь».

### Типы файлов
- Иконка по расширению или маске (*.log, readme.*), группы расширений (.jpg/.jpeg/.png).
- «Открывать через» для конкретных типов; импорт/экспорт правил.

### Настройки
- Отдельные шрифт, размер и цвет для плиток, вкладок и интерфейса.
- Светлая/тёмная тема, русский и английский интерфейс.
- Автозапуск, поведение трея, запоминание активной вкладки, авто-выход из папки по простою.
- Сохранение и восстановление бекапа настроек (INI-файл).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+J (настраивается) | Показать окно панели |
| Ctrl+F / печать | Поиск по панели |
| Esc | Закрыть поиск / окно |
| Ctrl+клик по папке | Открыть мини-проводник |
| Ctrl+колесо | Размер шрифта консоли |

## Сборка

Требуется .NET Framework 4.x (компилятор есть в системе):

```
build.bat
```

или напрямую:

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /win32icon:app.ico /out:WinPanel.exe src\*.cs
```

## Файлы данных

Создаются рядом с exe:

| Файл | Назначение |
|---|---|
| `settings.ini` | Все настройки |
| `records.xml` | Вкладки, папки и ярлыки |
| `bookmarks.xml` | Закладки мини-проводника |
| `filetypes.xml` | Правила по типам файлов |
| `ico\` | Копии ярлыков и пользовательских иконок |

## Структура исходников (`src/`)

| Файл | Назначение |
|---|---|
| `Program.cs` | Главное окно: вкладки, плитки, панельный поиск, попапы папок |
| `MiniExplorerForm.cs` | Мини-проводник: навигация, закладки, консоль |
| `SearchCore.cs` | Индексация дисков, fuzzy-скоринг, битовые маски |
| `PanelSearch.cs` | Метаданные сохранённых элементов для поиска |
| `Settings.cs` / `SettingsForm.cs` | Модель и окно настроек |
| `FileTypes.cs` / `FileTypesForm.cs` | Правила по типам файлов и их редакторы |
| `Bookmarks.cs` | Хранение закладок |
| `Loc.cs` | Локализация RU/EN |
| `IconExtractor.cs`, `NativeContextMenu.cs`, `IniFile.cs`, `Records.cs` | Иконки, системные меню, INI, хранение записей |
